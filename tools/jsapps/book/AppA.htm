This appendix gathers the JavaScript this book uses beyond the first book, grouped by subject, with a short example of each. The chapter that explains each idea is given in brackets; (Part Two) marks things first met in the organiser's code. The first book's appendix A covers everything it taught.

Classes

A class describes a kind of object: the information each one holds and the methods that work on it.

class Book {                                                (1)
  constructor() {           // runs when one is made       (1)
    this.contacts = new Map();   // this: the object itself
  }
  add(c) { ... }            // a method                    (1)
  get size() {              // used without brackets:      (1)
    return this.contacts.size;   //   book.size
  }
  static fromJSON(data) {   // belongs to the class, not   (7)
    ...                     // to one Book: Book.fromJSON()
  }
}
const book = new Book();    // make one                    (1)

class Book extends Emitter {    // a Book is an Emitter too (1)
  constructor() {
    super();                // run Emitter's constructor   (1)
    ...
  }
}
A set method, the partner of get, runs when a property is given a value (set name(v) { ... }). The desktop's TextArea uses one for text (not written in this book).

Maps and Sets

const m = new Map();                                        (1)
m.set(3, ann);   m.get(3);   m.has(3);   m.delete(3);
m.size;   [...m.values()];   [...m.keys()]
for (const [id, c] of m) { ... }

const s = new Set();        // each thing at most once     (1, 7)
s.add('Ann');  s.has('Ann');  s.delete('Ann');  s.size
[...s]                      // an array of what's in it
A Map finds a value by its key without looking through everything; a Set answers "is this in it?" quickly. The toolkit's Emitter keeps a Map of Sets of listeners, and ListView a Set of selected keys.

Spread and rest

{ ...fields, id }           // a new object: fields' properties
                            //   copied in, then id       (1)
[...list, item]             // a new array with one more  (1)
f(...args)                  // an array as arguments
const { kind, ...rest } = x;    // rest: x without kind   (Part Two)
Making a new object rather than changing the old one is what lets a dialogue box edit a copy (chapter 3) and Undo put the old one back (chapter 9).

Choosing values

a ?? b          // a, unless it's null or undefined     (1)
x ??= 'none'    // give x a value if it hasn't one      (3)
c?.name         // c.name, or undefined if c is null    (3)
f?.()           // call f if there is one               (3)
ok ? 'Yes' : 'No'   // the conditional operator         (3, 4)

switch (ev.code) {                                      (4)
  case 0x18E: this.move(1); break;
  case 0x18F: this.move(-1); break;
  default: return undefined;
}

Waiting: Promises, async and await

function ask() {                                        (3)
  return new Promise((resolve) => {
    ...                      // later, when there's an answer:
    resolve(values);
  });
}
async function edit() {      // may wait, with await     (3)
  const values = await ask();
  ...
}
An async function returns a Promise at once; its code carries on after each await when the thing waited for is ready. Meanwhile the desktop goes on as usual.

Objects

Object.assign(this, { win, top })  // copy properties in   (2)
Object.entries({ a: 1 })     // [['a', 1]]                 (6)
Object.fromEntries([['a', 1]])   // { a: 1 }         (Part Two)

A toJSON method says what an object becomes in a file. A saved file carries a format name and a version number, so a later program can tell what it's reading (chapter 7; appendix E).

Strings and regular expressions

a.localeCompare(b)           // -1, 0 or 1, for sorting     (1)
a.localeCompare(b, undefined, { sensitivity: 'base' })      (6)
name.startsWith('Mr')  name.endsWith('/vcf')               (3)
/^(\d+)\/(\d+)$/.exec(s)     // the match and its groups    (3)
new RegExp(`\\b${t}\\b`)      // a pattern made from text     (8)
/(?<!\\);/                   // ; but not after \  (lookbehind) (8)
s.replace(/x/g, (m) => ...)  // replace using a function    (8)
exec gives null if the pattern doesn't match, otherwise an array: the whole match, then each bracketed group.

Text and bytes

new TextDecoder('utf-8', { fatal: true }).decode(bytes)     (8)
new TextEncoder().encode(text)    // text to UTF-8 bytes    (8)
RISC OS text is Latin-1, one byte per character; files from other computers are usually UTF-8. The toolkit's Formats module turns one into the other (chapter 8).

Dates

new Date(2026, 8, 25, 12)    // months count from 0!   (Part Two)
d.getFullYear()  d.getMonth()  d.getDate()  d.getDay()
d.setDate(d.getDate() + 7)   // a week on: overflows into
                             //   the next month by itself
new Date(2026, 9, 0).getDate()   // 30: days in September
The toolkit's Dates module keeps days as keys such as '2026-09-25' and uses Date only inside itself, at midday, so that summer time never moves a day (appendix B).
