This appendix collects tips for writing programs in JsEdit, for running them from a task window, and for keeping your programs on the computer your web browser is running on, where you can use another editor if you prefer.

JsEdit for programmers

JsEdit is built on Edit, the desktop's ordinary text editor, so Edit's keys and most of its menus work in it too. What JsEdit adds is help with programs. Its own help (Shift-double-click !JsEdit and open !Help) describes everything; these are the parts you'll use most.

Making and opening programs

  • JsEdit is HardDisc4.$.Apps.!JsEdit: double-click it to put its icon on the icon bar.

  • Click Select on the JsEdit icon to start a new JavaScript program. Click Menu on the icon and choose Create for other kinds of file: BASIC, Obey, JSON or plain Text.

  • Double-clicking a program runs it. To open it in JsEdit instead, hold down Shift while you double-click it, or drag it onto the JsEdit icon.

  • If you saved a program as a Text file by mistake, change its type with Menu > Misc > Set type (type JSScript and press Return, then save it again), or with Set type on the Filer's File menu.

The toolbar

Save
Save the program (F3 does the same).

Run
Save the program, check it, and run it (Ctrl-R). For an application's !RunImage, Run runs the whole application.

Check
Check the program's syntax and say whether it is all right.

Find, Goto
Find (and replace) text; go to a line (F4, F5).

Functions
List the functions defined in the program. Click one to go to it.

Errors
Open the Throwback window (below).

At the right of the toolbar is the program's mode and the caret's line and column. Click the mode to change it.

Indenting

Return starts the new line with the same indent as the one before, and one step (two spaces) further in after an opening bracket - {, ( or [. Typing a closing bracket at the start of a line moves it back a step, so it lines up with the line that opened it. Tab moves the caret on to the next step, and Shift-Tab back; with several lines selected, they move the whole selection in or out. Everything is done with spaces, which is what this book's programs use.

Menu > Edit > Comment puts // in front of the selected lines (or the caret's line), or takes it away again: a quick way to switch part of a program off while you try something.

Completion

As you type a name, JsEdit offers a list of names that could finish it: the things this book's programs have ready to use (print, task.every, w.useCanvas ...), with a line about each at the bottom of the list, JavaScript's own words, and names already in your program. Use Up and Down to choose, Return or Tab to put the name in, and Escape (or just keep typing) to ignore the list. Press Ctrl-Space to ask for the list at any time. Menu > Display > Completion turns it off.

Mistakes and throwback

A moment after you stop typing, JsEdit checks that JavaScript can understand the program. If it can't, the line number of the first mistake turns red and the line is shaded, until you put it right.

When a program you run with Run goes wrong while it is running, the error comes back to JsEdit (throwback) instead of appearing in an error box: the Throwback window lists it, the line is marked, and the caret is put on it. Click an error in the Throwback window to go back to its line. The messages are the same as in the error boxes (appendix C). A program run by double-clicking it still reports its errors in error boxes - unless JsEdit is showing that program, in which case they come back to JsEdit too.

Modes

JsEdit colours BBC BASIC listings, Obey files and JSON as well as JavaScript. Each kind of file has a mode, chosen from the file's type; you can change it from the toolbar or Menu > Mode. Modes are text files in !JsEdit.Modes, which say which words are keywords, which colours to use and so on; JsEdit's help explains how to change them.

Display

Menu > Display has Edit's choices of font, colours and so on, and JsEdit's own switches: Line numbers, Bold keywords, Caret line (the shading of the line the caret is on), Completion and Dark theme, which shows the text in light colours on a dark background - easier on the eyes for long sessions. JsEdit remembers your choices.

JsEdit uses the RISC OS system font unless you choose another in Menu > Display > Font list. Besides the RISC OS fonts, the list has three fonts designed for programming: JetBrainsMono, Hack and FiraCode. They are "Nerd Fonts", which also hold thousands of small icons (see chapter 7 for drawing them from a program). Choose Medium or Bold, then set Font size: 11 or 12 is comfortable.

Keeping lines short

JsEdit doesn't wrap long lines, so a long line runs off the right of the window. Keep lines to 70 characters or so, splitting a long statement after an operator or a comma (JavaScript doesn't mind), and make the window wide enough to see them.

Using Edit instead

Edit, in the Apps on the icon bar, can edit programs too, if you prefer it. To start a new program in Edit, click Menu on the Edit icon, move to Create, type JSScript in the box at the bottom of the menu and press Return. Edit has no colours, line numbers, checking or Run button, and its Tab key works differently: it moves the caret along to line up with the start of the next word on the line above (so at the start of a new line it takes you to the indent above), or, with Column tab turned on (Shift-F3), to the next multiple of eight columns.

Running programs from a task window

A task window is a window where you can type * commands while the desktop carries on. Press Ctrl-F12 to open one, then run a program by typing its name after JSRun:

*JSRun HardDisc4.$.MyProgs.Hello
Typing the full name each time is tedious, so first make your directory the current directory with *Dir; after that the program's own name is enough:

*Dir HardDisc4.$.MyProgs
*JSRun Hello
*JSRun Greet
A program run from a task window prints in the task window, and input reads what you type there. Anything after the program's name is passed to it in ctx.args (and, split into words, ctx.argv), so a program run with

*JSRun MyProgram red 12
finds 'red 12' in ctx.args and ['red', '12'] in ctx.argv.

Keeping programs on your own computer

Your programs are normally kept on the desktop's hard disc, which your web browser stores for you. With HostFS you can keep them in a folder on your own computer instead. They are then safe even if the browser's stored data is cleared, and you can edit them with any editor you like, then run them in RISC OS. HardDisc4.$.Docs.HostFS explains HostFS fully; here is how to use it for programs.

Mounting a folder

1 Make a folder on your computer for your programs.

2 Click Select on the HostFS icon on the icon bar and choose the folder. (This needs Chrome, Edge or another Chromium browser. In other browsers, start the desktop's server with the folder named, as the HostFS guide explains.)

3 The folder appears on the icon bar with its name, for example Progs, and as a disc, HostFS::Progs.$. Click it to open it.

Program names

Your computer keeps file types in file names, so a JavaScript program there needs a name ending .js, such as hello.js. RISC OS shows it as hello/js, with the JSScript icon, and double-clicking it runs it. Programs you save into the folder from JsEdit are named for you: save a JSScript file called hello/js and it appears on your computer as hello.js; save one called just Hello and it appears as Hello,f81 (,f81 is how HostFS records the file type when the name doesn't show it).

In a module, import another file as usual. './Board' finds a file called Board or Board/js, so the same program works whether its files have the ending or not; you can also write the ending, as programmers elsewhere do:

import { drawBoard } from './Board.js';     // Board/js (or Board)

Applications

Application directories work in a HostFS folder too, but their special files need their types recorded in their names: !Run,feb (Obey), !RunImage,f81 (JSScript), !Sprites,ff9 (Sprite). The easiest way to get them right is to make the application in RISC OS, or copy one such as !Snake into the HostFS folder with the Filer: HostFS names every file for you.

Editing on your computer

Open the .js file in your computer's editor, change it and save it. RISC OS sees the change when you next open the directory display, or when you come back to the browser window, and double-clicking the program always runs the latest version. Most programmers' editors also colour JavaScript's keywords and strings and point out many syntax mistakes as you type, much as JsEdit does.

Note: if you edit the same program in JsEdit and on your computer at the same time, whichever saves last wins. Close it in one before changing it in the other.
