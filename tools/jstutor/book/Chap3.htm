So far your programs have carried out every statement once, from top to bottom. Real programs need to make choices - do this if that is true - and to repeat things. In this chapter you will learn how, and write a times table program, the counting game FizzBuzz, and a guessing game.

True and false

Besides numbers and strings, JavaScript has two more values: true and false. They are called booleans, after the mathematician George Boole. You get them by comparing things:

print(3 < 5);          // true
print(3 > 5);          // false
print(2 + 2 === 4);    // true
These are the comparison operators:

Operator  Meaning                      Example        Result
  ===     is equal to                  5 === 5        true
  !==     is not equal to              5 !== 5        false
   <      is less than                 3 < 5          true
   >      is greater than              3 > 5          false
   <=     is less than or equal to     5 <= 5         true
   >=     is greater than or equal to  3 >= 5         false
"Is equal to" is written with three equals signs. One equals sign already means "becomes", as you saw in chapter 2, so it can't also mean "is equal to".

Note: JavaScript also has == and !=, with two equals signs. They try to be helpful by converting values before comparing them, so '1' == 1 is true, and so, less helpfully, is 0 == ''. The rules are complicated and a common source of mistakes. Always use === and !==, which compare values exactly as they are: '1' === 1 is false, because a string is never equal to a number.

Strings can be compared too. === checks whether two strings are exactly the same, capital letters and all, so 'yes' === 'Yes' is false.

Making decisions: if

An if statement runs some statements only when something is true:

const age = Number(await input('How old are you? '));
if (age >= 18) {
  print('You can vote.');
}
print('Thank you.');
The comparison goes in brackets after if, and the statements to run go between curly brackets, { and }. Statements between curly brackets are called a block. If the comparison is true, the block runs; if not, it is skipped. Either way the program carries on after the closing bracket, so Thank you. is always printed.

The statements inside the block are indented - moved in by two spaces - so you can see at a glance which statements belong to the if. JavaScript doesn't mind how you lay the program out, but people do. JsEdit helps: when you press Return it starts the new line with the same indent as the one before, one step (two spaces) further in after a {, and typing } at the start of a line moves it back out. Tab indents by a step, and Shift-Tab outdents; select several lines first to move them all. Appendix D has more.

else

Add else and a second block to say what to do when the comparison is false:

if (age >= 18) {
  print('You can vote.');
} else {
  print(`You can vote in ${18 - age} years.`);
}
Exactly one of the two blocks runs. For more than two choices, chain them with else if:

if (age < 13) {
  print('Child');
} else if (age < 20) {
  print('Teenager');
} else {
  print('Adult');
}
JavaScript tries each comparison in turn, from the top, and runs the block of the first one that is true. The rest are skipped. The last else catches anything that got past all the others.

And, or, not

You can combine comparisons:

Operator  Meaning   True when ...
   &&     and       both sides are true
   ||     or        either side is true, or both
   !      not       the value after it is false
For example:

if (age >= 13 && age <= 19) {
  print('Teenager');
}
if (answer === 'y' || answer === 'yes') {
  print('OK');
}
Notice that each side of && and || has to be a complete comparison: answer === 'y' || 'yes' doesn't do what it seems to say.

Repeating things: for

Computers are good at doing the same thing many times. A for loop repeats a block with a counter that goes up each time round:

for (let i = 1; i <= 5; i++) {
  print(`This is time number ${i}`);
}
This prints five lines, numbered 1 to 5. The brackets after for hold three parts, separated by semicolons:

let i = 1
makes the counter, a variable called i, and starts it at 1. This is done once, before the loop starts.

i <= 5
is checked before each time round. While it is true the block runs; as soon as it is false the loop stops and the program carries on after it.

i++
is done after each time round. i++ is a short way of writing i = i + 1: it adds one to i.

FizzBuzz

FizzBuzz is a counting game. Players count in turn, but say "Fizz" instead of any number that divides by 3, "Buzz" instead of any number that divides by 5, and "FizzBuzz" for numbers that divide by both. It is also a famous little programming puzzle, because it needs a loop and a decision together.

How does the program know whether a number divides by 3? It uses the remainder operator from chapter 2: i % 3 is the remainder when i is divided by 3, and a number divides exactly when the remainder is 0.

The order of the tests matters. 15 divides by 3, so if the test for 3 came first, 15 would be "Fizz". The test for both comes first, so that it gets the first chance.

There are two new things in this program.

let word; makes a variable without giving it a value yet. Until it is given one, its value is undefined, JavaScript's way of saying "nothing here". Each branch of the if then gives word a value. String(i) turns a number into a string, the opposite of Number.

Instead of printing each word on its own line, which would fill the window, the program builds up a line at a time in line, and prints it after every ten numbers - when i % 10 is 0 - before starting again with an empty string.

Notice also that a variable made inside a block only exists inside it. word is made afresh each time round the loop. line has to last from one time round to the next, so it is made before the loop starts.

Repeating until something happens: while

A for loop is best when you know how many times to go round. When you don't, use a while loop, which repeats its block for as long as a comparison is true:

let answer = '';
while (answer !== 'yes') {
  answer = await input('Are we there yet? ');
}
print('Hooray!');

Random numbers

Games need some luck. Math.random() gives a different random number each time you call it, somewhere between 0 and 1 (it can be 0, but it is always less than 1), such as 0.7342. To turn it into a whole number from 1 to 100:

Math.floor(Math.random() * 100) + 1
Math.random() * 100 is between 0 and 99.999..., Math.floor rounds it down to a whole number from 0 to 99, and adding 1 gives 1 to 100.

A guessing game

while (true) looks as though it would go round for ever, since true is always true. The way out is break, which stops a loop immediately and carries on after it. Here that happens when you guess the number. break works in for loops too.

The program counts your guesses in guesses, which starts at 0 and has one added each time round.

Warning: a loop that never ends, and never waits for you to type something, stops the whole desktop: nothing else can run until it finishes, and it never does. If this happens, reload the page in your web browser. Anything you have saved is safe on the hard disc, but save your program before running it, in case. For example, this loop never ends, because i is never changed:

let i = 1;
while (i <= 10) {
  print(i);
}

Summary

  • true and false are booleans. Comparisons (===, !==, <, >, <=, >=) give a boolean. Use ===, not ==.

  • && (and), || (or) and ! (not) combine them.

  • if (...) { ... } else if (...) { ... } else { ... } runs the first block whose comparison is true.

  • for (let i = 1; i <= 10; i++) { ... } repeats a block with a counter; while (...) { ... } repeats it for as long as something is true. break leaves a loop early.

  • Math.floor(Math.random() * n) + 1 is a random whole number from 1 to n.

  • A variable made inside a block only exists inside that block.
