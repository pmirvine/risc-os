A variable holds one value. Often you need to keep many values together: a list of scores, the words of a sentence, all the details of a player. JavaScript has two ways of doing that: arrays and objects. In this chapter you will use both, to keep a table of top scores and to take a sentence to pieces.

Arrays

An array is a list of values, written between square brackets and separated by commas:

const days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'];
const primes = [2, 3, 5, 7, 11, 13];
const nothing = [];
print(days);          // ["Mon", "Tue", "Wed", "Thu", "Fri"]
Each value in an array is called an element, and has a number, called its index, which says where it is in the list. You use the index, in square brackets, to get the element:

print(days[0]);       // Mon
print(days[1]);       // Tue
print(days[4]);       // Fri
Indexes start at 0, not 1. The first element is days[0], and the last of these five is days[4]. This takes some getting used to, but almost every programming language does it. If you ask for an index that isn't there, such as days[9], you get undefined.

length is the number of elements, so the last element is always days[days.length - 1]. You can also change an element by giving it a new value:

print(days.length);   // 5
days[0] = 'Monday';
print(days[0]);       // Monday

Adding to an array

push adds an element to the end of an array, and the array gets one longer:

const shopping = [];
shopping.push('bread');
shopping.push('milk');
print(shopping);          // ["bread", "milk"]
print(shopping.length);   // 2
push is a method: a function that belongs to a value, and is called with a dot after the value's name - shopping.push('bread') means "the array shopping, add 'bread' to yourself". You have met methods before without the name: toUpperCase and toFixed in chapter 2 are methods of strings and numbers. Arrays have many methods, and the rest of this chapter uses several.

You might be surprised that shopping is made with const and yet it changes. const means the variable always holds the same array; it doesn't stop the array itself from being changed. You can't give shopping a different array, but you can put things in the one it has.

Going through an array

You could go through an array with a for loop and an index, counting from 0 up to one less than the length:

for (let i = 0; i < days.length; i++) {
  print(`Day ${i + 1} is ${days[i]}`);
}
When you don't need the index, for...of is simpler. It takes each element in turn:

for (const day of days) {
  print(day);
}
Read it as "for each day of days". Each time round, day is the next element.

Useful array functions

days.join(', ')          a string of all the elements, with ', '
                         between them: 'Monday, Tue, Wed, Thu, Fri'
days.includes('Wed')     true if 'Wed' is in the array
days.indexOf('Wed')      the index of 'Wed' (2), or -1 if not there
days.reverse()           turns the array back to front
days.sort()              puts the array in order
reverse and sort change the array itself, rather than making a changed copy as the string functions do.

sort on its own sorts the elements as though they were strings, in alphabetical order. For words that is what you want (though capital letters come before small ones), but for numbers it gives odd results: [10, 9, 1].sort() gives [1, 10, 9], because as a string, "10" comes before "9". To sort in any other order, give sort a function - you saw how to pass a function to a function in chapter 4:

const numbers = [10, 9, 1, 25];
numbers.sort((a, b) => a - b);
print(numbers);          // [1, 9, 10, 25]
sort calls your function whenever it needs to know which of two elements, a and b, should come first. The function answers with a number: less than 0 if a should come first, more than 0 if b should, and 0 if it doesn't matter. a - b does just that for numbers, sorting them from smallest to largest; b - a sorts them from largest to smallest.

Objects

An array is a list of values, found by number. An object is a collection of values found by name. Each value has a name, called a property. You write an object between curly brackets, as pairs of names and values:

const player = { name: 'Ann', score: 120, level: 3 };
print(player.name);       // Ann
print(player.score);      // 120
print(player);            // {name: "Ann", score: 120, level: 3}
You get a property with a dot, as with length. You can change a property, or add a new one, by giving it a value:

player.score = player.score + 50;
player.lives = 3;
Asking for a property the object doesn't have gives undefined.

Objects are useful whenever several values belong together. Rather than three separate variables playerName, playerScore and playerLevel, you have one variable, player, holding everything about the player. You have been using objects all along: Math is an object, and Math.PI is one of its properties.

Arrays of objects

Arrays and objects can hold any values, including other arrays and objects. An array of objects is one of the most common ways of keeping data in a program:

const players = [
  { name: 'Ann', score: 120 },
  { name: 'Bob', score: 85 },
];
print(players[1].name);   // Bob
players[1] is the second object, and players[1].name is its name. Notice the comma after the last element: JavaScript allows it, and it makes it easier to add more lines later.

Summary

  • An array is a list of values, [1, 2, 3]. Elements are numbered from 0: list[0] is the first, list[list.length - 1] the last.

  • push adds to the end; join, includes, indexOf, reverse and sort are other useful methods - functions that belong to a value and are called with a dot, list.push(x).

  • for (const item of list) { ... } goes through every element.

  • sort((a, b) => a - b) sorts numbers; the function says which of two elements comes first.

  • split turns a string into an array.

  • An object, { name: 'Ann', score: 120 }, is a collection of named values, got with a dot: player.name.

  • Arrays of objects are a good way of keeping tables of data.

  • padStart and padEnd line up columns.
