Reference screenshots of Acorn RISC OS 3.5-3.71 ("NewLook" 3D desktop)
======================================================================
Downloaded 2026-09-24. All captures are unscaled screen grabs unless the
filename contains "-scaled". Prefixes: ro37 = RISC OS 3.7x, ro370 = 3.70,
ro35 = RISC OS 3.5/3.6 (NewLook, bitmap system font), ro31 = RISC OS 3.1x
(flat 2D furniture, kept only as fallback for things not found in 3.5+).

Source abbreviations:
  GG  = https://guidebookgallery.org/screenshots/riscos37  (images at https://guidebookgallery.org/pics/gui/...)
  TC  = https://telcontar.net/Misc/GUI/RISCOS/  (images at https://telcontar.net/Misc/GUI/RISCOS/<name>)
  WMC = Wikimedia Commons
  UG  = RISC OS 3.7 User Guide, http://www.riscos.com/support/users/userguide3/bookb/  (manual illustrations)
  TT  = http://toastytech.com/guis/riscos.html

General observations (3.7, outline desktop font = Homerton-like sans, ~12px cap height at 800x600):
  - Backdrop: mid-grey marble/stone texture with tiled faint "Acorn" + acorn logo watermark (Screen config texture 3).
  - Icon bar: ~67px tall strip at bottom, light grey with white/grey speckled paper texture, 3D raised
    top edge; devices at left (:0 floppy, HardDisk, Apps), tasks at right, green acorn Task Manager icon far right.
  - Window furniture: 3D bevelled grey tool icons. Title bar left-to-right: back (two overlapping squares),
    close (X), title, toggle-size (square in square) at right. Right scroll bar with up/down arrows
    and a bevelled grey well; bottom horizontal scroll bar with left/right arrows; resize icon bottom-right.
  - Title bar: focused (input focus) window title is cream/pale-yellow with a speckled texture; unfocused
    titles are light grey with speckled texture. Title text black, centred.
  - Window work area backgrounds: light grey (#dddddd-ish) with subtle white "crackle/marble" texture;
    text windows (Edit/Task window) have plain white work area.
  - Menus: title bar in dark-ish grey with black centred text; body white, black text; selected item
    inverted (black background, white text); shaded items mid grey; submenu arrow is a small grey
    right-pointing triangle at right; separators are dashed lines; ticks drawn as check marks at left.
    Menu has 3D grey border.
  - Buttons: grey 3D bevelled "action" buttons; default button has extra cream/yellow outer ring.
  - Writable fields: white sunken boxes; display fields: grey sunken boxes with centred text.
  - Option (radio) buttons: grey 3D circles, selected has black dot; checkboxes: 3D grey squares with a tick.
  - Bumpers: grey outline down/up triangles next to numeric fields; pop-up menu icon is a small
    "menu" glyph (arrow + list) at right of display fields.
  - Group boxes: etched (bevelled) rounded-corner rectangles with label breaking the top edge.
  - Task Manager: dark grey section header bars with white text ("Application tasks", ...), green
    bars for used memory, red bars for draggable values.
