# !Meteors

Code: `src/apps/Meteors/` (`app.js` descriptor, `main.js` game, `shapes.js` generated by
`node src/apps/Meteors/genshapes.mjs` from `vendor/.../Diversions/Meteors/s/MetShapes`).
App dir: `ADFS::HardDisc4.$.Diversions.!Meteors` (its `!Run` → `*Meteors_Start`, also registered as a command).

Port of Neil Raine's Meteors module 0.18 (`s/Meteors`, ARM assembler), keeping its behaviour:

* Windows from `assets/templates/Meteors.json`: `Arena` (black, scroll bars, "Meteors"), `Scores` pane
  (frameless, Score / ship sprites for spare lives / Sheet) and `FullArena`. No icon bar icon, no menu, no
  sound - as the original. Closing the window quits (multi-instance, like the module).
* 16.16 fixed-point screen-pixel coordinates (y up), object queues (ship, 80 rock slots with 26 moved per
  step, 4 bullets, 5 explosion fragments), one game step per 2 cs (no backlog), same PRNG, velocities,
  sheet progression (4 rocks, +1 per sheet up to 20; faster rocks and splits), scores 20/50/100, extra ship
  every 10000, 3 ships, 81-cycle rebirth with the "clever" 32-cycle look-ahead for a safe re-entry,
  hyperspace (1 s, then 1 in 5 chance of death - the original's intended 1 in 3 never happens because of a
  flags bug), bitmap collision detection with wrap, pixel shapes plotted by EOR (overlaps XOR in
  Wimp-colour space: ship/explosions yellow, rocks light blue, bullets red). Objects stay fixed relative to
  the work area when the window is moved/scrolled (`correctcoords`); shapes wrap pixel by pixel at the edges.
* Keys: Z/X rotate, Shift thrust, Return fire (edge-triggered), Space hyperspace / new game after
  "Game over" (Trinity 30pt, centred), N new sheet, Copy(End) pause, Delete resume, Escape full screen
  (pointer hidden; Escape again returns). Any click on the window toggles the input focus; the game only
  runs while Meteors has the caret.
* Test hook: `task.meteors.state` / `.killship()`. Tests: `tests/div/meteors.mjs`, `meteors2.mjs`
  (screens `tests/screens/div-meteors*.png`).
