# Assets (owned by the assets agent)

Everything under `assets/` is generated by node scripts in `tools/` from `vendor/ro371/`
(re-run them; don't hand-edit outputs). Zero runtime deps. Status: see "Report" at the end.

Rebuild everything: `node tools/build.mjs` (fonts need `cd tools && npm i` once — opentype.js is the only
dev dep, in `tools/package.json`, deliberately separate from any root package.json).

| What | Command | Output |
|---|---|---|
| Sprites | `node tools/sprites.mjs --build` | `assets/sprites/<Pool>/<File>.json` + PNGs, `index.json`, contact sheet `assets/sprites/index.html` |
| Templates | `node tools/templates.mjs --build` | `assets/templates/<Pool>[.<File>].json`, `index.json` |
| Messages, !Help | `node tools/messages.mjs --build` | `assets/messages/<Pool>.json`, `assets/help/<App>.txt` (+ `index.json` each) |
| System font | `node tools/sysfont.mjs` | `assets/fonts/system8x8.json`, `system8x8.png` |
| Outline fonts | `node tools/fonts.mjs` | `assets/fonts/*.otf`, `fonts.css`, `fonts.json`; test page `assets/fonts/test.html` |
| Palette, filetypes | `node tools/misc.mjs` | `assets/palette.json`, `assets/filetypes.json` |
| Seed disc | `node tools/disc.mjs` | `assets/disc/HardDisc4/…`, `assets/disc/manifest.json`, `skipped.json` |

Shared helpers: `tools/lib/png.mjs` (PNG encoder), `lib/spritefile.mjs`, `lib/palette.mjs`,
`lib/riscosfont.mjs` (Outlines/IntMetrics/encoding parsers), `lib/sources.mjs` (pool naming, excludes).
Pool = one app/module, same naming across sprites/templates/messages (e.g. `Filer`, `Draw`, `SciCalc`).

## 1. Sprites

### Layout

```
assets/sprites/index.json                 { <Pool>: { <File>: {source, count} } }
assets/sprites/<Pool>/<File>.json         manifest for one sprite file (e.g. Wimp/Sprites22.json)
assets/sprites/<Pool>/<File>/<name>.png   one RGBA PNG per sprite (alpha from mask)
assets/sprites/<Pool>/<File>/<name>.sq.png  square-pixel version (only for rectangular-pixel sprites)
assets/sprites/index.html                 contact sheet: ?pool=Wimp&file=Sprites22&zoom=2&filter=file_
```

Manifest entry, keyed by **lower-case** sprite name (RISC OS sprite names are case-insensitive):

```json
"file_fff": { "w":34, "h":34, "file":"Sprites22/file_fff.png", "xeig":1, "yeig":1,
              "osW":68, "osH":68, "bpp":4, "hasMask":true, "hasPalette":false,
              "fileSq":"...sq.png", "wSq":.., "hSq":.., "eigSq":1 }   // fileSq* only when xeig != yeig
```

* `file` is relative to the pool directory (`assets/sprites/<Pool>/`).
* `osW/osH` = size in OS units (`w << xeig`, `h << yeig`). **Draw at CSS size osW/2 × osH/2**
  for the default 1 px = 2 OS unit desktop — this automatically doubles mode-12 (yeig=2) sprites
  vertically (use `image-rendering: pixelated`), or use `fileSq` which is pre-doubled.
* PNG filenames: lower-case name; any char outside `[a-z0-9_!-]` is written as `~hh` (hex).
  E.g. the Wimp's menu arrow sprite named `"\x89"` → `~89.png`, tick `"\x80"` → `~80.png`.
  Manifest keys keep the real (Latin-1) name, e.g. `"\u0089"`.
* Colours: sprites without their own palette use **Wimp colour translation** (what the desktop
  shows): 1bpp → Wimp colours 0/7 (white/black), 2bpp → Wimp 0/2/4/7, 4bpp → Wimp palette,
  8bpp → default 256-colour VIDC palette. 16/32bpp are direct colour.
* Pointer sprites (`ptr_*`, 2bpp): colour 0 transparent, 1 = cyan, 2 = dark blue (#000099), 3 = red.
* Browser use: `tools/lib/spritefile.mjs` (+ `tools/lib/palette.mjs`) are dependency-free ES modules
  that also work in the browser — `parseSpriteFile(Uint8Array)` returns `{name,w,h,bpp,xeig,yeig,hasMask,rgba}`
  for decoding sprite files found on the virtual disc at runtime (`new ImageData(new Uint8ClampedArray(s.rgba), s.w, s.h)`).

### Pools

A pool is one app/module. Sources: `Install/HardDisc4` first, then `Internat/Messages/UK`, then the rest of `Sources/`.

* **`Wimp`** — the Wimp's ROM sprites (from `Sources/OS_Core/Desktop/Wimp/Resources/UK/`):
  * `Tools3d` — **RISC OS 3.5+ 3D window furniture (use this)**. Names: `bicon` back, `cicon` close,
    `ticon`/`ticon1` toggle-size (normal/toggled), `sicon` adjust-size, `uicon`/`dicon`/`licon`/`ricon`
    scroll arrows, `blicon` blank (corner filler), `tbarlcap`/`tbarmidt`/`tbarmidb`/`tbarrcap` title bar
    (left cap, middle top/bottom strips — masked, the title colour shows through the transparent part —
    right cap), `vwelltcap/vwellt/vwellb/vwellbcap` vertical scroll well, `vbart/vbarmid/vbarb` vertical
    scroll bar sausage, `hwelllcap/hwelll/hwellr/hwellrcap` + `hbarl/hbarmid/hbarr` horizontal. `p` prefix =
    pressed/selected state (`pbicon`, `pvbarmid` …). Each exists at mode-12 resolution (no suffix, 22×11
    eig 1,2) and square-pixel **`…22`** suffix (20×20, eig 1,1) — **use the `22` versions**.
  * `Tools` — the old 2D (RISC OS 3.1 style) furniture, same naming, suffixes `0`,`22`,`23`.
  * `Sprites22` — **the Wimp sprite pool for square-pixel hi-res modes (use this)**; `Sprites` is the
    mode-12 equivalent, `Sprites23` the mono version. Contains: `directory`, `directoryo` (open),
    `application`, `small_dir`, `small_diro`, `small_app`, `file_xxx` (generic/untyped) and
    `file_<hex>` / `small_<hex>` per filetype (fff Text, ffb BASIC, ff9 Sprite, aff Drawfile, feb Obey,
    ff8 Absolute, ffa Module, fec Template, ffd Data, …), drive icons `floppydisc`, `harddisc`,
    `ramfs`, `network`, `fileserver`, `nodisc`, `discs`, `pcmcia*`; ROM app icons `!edit`,`!draw`,`!paint`,
    `!chars`,`!help`,`!calc`,`!configure`,`!alarm`,`!printers` (+ `sm!…` small versions), `palette`,
    `switcher` (Task Manager icon-bar acorn), `romapps` (Apps icon); dialog icons `optoff`/`opton`
    (option/tick boxes), `radiooff`/`radioon`, `yes`/`no`/`dontcare`, `tick`, `gright`/`pgright`
    (popup menu arrow), `up`/`down`/`left`/`right` (+`p` pressed) adjuster arrows, `error`, `warning`,
    `question`, `information`, `program`, `package`, `display`; menu glyphs `"\x80"` (tick, 12×12) and
    `"\x89"` (submenu arrow 10×10), `"\x88"` (8×16 mask glyph); pointers `ptr_default`, `ptr_double`,
    `ptr_write`, `ptr_confirm`; `tile_1` (the grey marble **window background texture** of 3.5+;
    `tile_1-8`/`tile_1-16` 8/16bpp variants), `divider`, `artaclogo` (Acorn banner).
  * `MySprites4`, `SpritesNL` — spare/variant pools found alongside (not used by default).
* **`Pinboard`** — `!Sprites`, `LCDTile`. **`Textures`** — the Configure backdrop / window textures
  `T1`..`T7` (+`L` light variants), from `!Boot/Resources/Configure/Textures`.
* **`Configure`** — `Sprites`/`Sprites22` (Configure window icons), `tile_1`, `2DTools`.
* Per-app pools named after the app without `!`: `Draw`, `Paint` (`Sprites22` = tool pane icons),
  `Edit`, `Maestro`, `SciCalc`, `Squash`, `CloseUp`, `ChangeFSI`, `PhotoView`, `Patience`, `MineHunt`,
  `Meteors`, `Blocks`, `Puzzle`, `Clock`, `MemNow`, `Flasher`, `Player`, `Printers`, `Printers-dp/-lj/-ps`,
  `Boot`, `System`, `Scrap`, `Fonts`, `ARMovie`, `ARPlayer`, `Bookworm`, `Verify`, `HForm`, `FontPrint`,
  `PrintEdit`, `T1ToFont`, `SaveCMOS`, `ResetBoot`, `Picker`, `Display`, `BatMgr`, `CDPlayer`,
  `Homerton`, `Darwin`, `WIMPSym` … — see `index.json`. Each has `!Sprites` (mode 12, application icon
  `!name` + `sm!name`), usually `!Sprites22` (**prefer for the desktop**) and sometimes `Sprites`/
  `Sprites22` (the app's own internal sprites, e.g. Patience cards, MineHunt tiles).
* ROM apps (Edit, Draw, Paint, Chars, Help, Alarm, Configure, Printers, Calc) get their icon-bar /
  filer icons from the **Wimp** pool (`Wimp/Sprites22`: `!draw`, `sm!draw` …), as in the real ROM.

## 2. Templates (`assets/templates/`)

`<Pool>.json` is the app's main `Templates` file; other template files in the same place become
`<Pool>.<File>.json` (e.g. `Edit.Templat2d.json` = 2D variant, `Wimp.Template3D.json`). Priority: the
ROM copy in `Internat/Messages/UK/Resources/<Module>/` (what 3.71 actually uses), then `Install/HardDisc4`, then `Sources`.
Useful ones: `Wimp` (backwindow, iconbar, error, command), `Filer` (directory, faccess, xfer_send, FileInfo),
`FilerAct`, `Pinboard`, `Switcher` (taskmenu, proginfo, shutdown, save …), `Desktop`, `Free`, `Draw`, `Edit`,
`Paint`, `Chars`, `Help`, `Alarm`, `Configure`, `SciCalc`, `Maestro`, `Squash`, `CloseUp`, `ChangeFSI`, `PhotoView`,
`MineHunt`, `Meteors`, `Blocks`, `MemNow`, `Player`, `Printers`, `Display`, `Picker*`, `ADFSFiler`, `NetFiler`, `BatMgr`.

```jsonc
{ "source": "Sources/.../Templates,fec",
  "fonts": [ {"xPoint":12,"yPoint":12,"name":"Homerton.Medium"} ],   // icon fontHandle N → fonts[N-1]
  "windows": { "<name>": {
    "visible": {xmin,ymin,xmax,ymax},     // screen OS units, origin bottom-left, y up
    "scroll": {x,y}, "behind": -1,
    "flags": 0xFF000012, "flagsDecoded": {…},  // see below
    "colours": {titleFg,titleBg,workFg,workBg,scrollOuter,scrollInner,titleFocus,extra}, // Wimp colours 0-15; 255 = none/transparent
    "extent": {xmin,ymin,xmax,ymax},       // work area; usually xmin=0,ymax=0, ymin negative
    "titleFlags": n, "titleFlagsDecoded": {…icon flags…}, "title": {text, bufferSize?, validation?, spriteName?},
    "workFlags": n, "workButton": 0-15, "workButtonType": "click",
    "spriteArea": 1,                        // 1 = Wimp sprite pool; else app's own sprites
    "minWidth": 0, "minHeight": 0,
    "icons": [ { "i": 0, "bbox": {xmin,ymin,xmax,ymax},   // work-area coords: (0,0) = top-left, y negative downwards
                 "flags": n, …decoded icon flags…, "text": "OK", "bufferSize": 12,
                 "validation": "R6,3", "validationParsed": {"R":"6,3"}, "spriteName": "…" } ] } } }
```

**Window flags** (`flagsDecoded`): `moveable` b1, `autoRedraw` b4 (Wimp redraws; no Redraw requests),
`pane` b5, `allowOffScreen` b6, `scrollRepeat` b8, `scrollDebounced` b9, `realColours` b10, `backWindow` b11,
`hotKeys` b12, `keepOnScreen` b13, `ignoreRightExtent` b14, `ignoreLowerExtent` b15; furniture (new format, b31 set):
`hasBack` b24, `hasClose` b25, `hasTitle` b26, `hasToggle` b27, `hasVScroll` b28, `hasAdjust` b29, `hasHScroll` b30.

**Icon flags** (decoded onto each icon): `text` b0, `sprite` b1, `border` b2, `hcentre` b3, `vcentre` b4,
`filled` b5 (fill with bg colour), `font` b6 (anti-aliased; then `fontHandle` = b24-31 instead of colours),
`needsHelp` b7 (app redraws), `indirected` b8, `rjustify` b9, `allowAdjust` b10 (Adjust doesn't cancel ESG
siblings), `halfSize` b11 (sprite plotted half size), `button` b12-15, `esg` b16-20 (exclusive selection group: selecting
one deselects others with the same non-zero ESG), `selected` b21, `shaded` b22, `deleted` b23, `fg` b24-27, `bg` b28-31.
If both text and sprite: sprite named by validation `S`, text drawn over/beside it (hcentre/vcentre/rjustify place them).

**Button types** (`buttonType`): 0 `never` (ignore clicks), 1 `always` (notify while pointer over), 2 `autorepeat`,
3 `click`, 4 `release`, 5 `doubleclick`, 6 `clickdrag`, 7 `releasedrag`, 8 `doubledrag`, 9 `menu` (select when pointer
over, like menu items), 10 `clickdoubledrag`, 11 `radio` (click selects & notifies), 14 `writeclickdrag`, 15 `writable`
(click places caret; typing edits text).

**Validation string** commands (`;`-separated, `\` escapes): `A` allowed chars (`A0-9` ranges, `~` negates),
`D` display char (password), `F` fg/bg colour pair in hex (`F27`), `K` keys (`KR` Return→next, `KA` arrows, `KT` Tab,
`KN` notify all keys, `KD` notify changes), `L` formatted multi-line text, `P` pointer sprite over icon (`Pptr_write`),
`R` 3D border type (`R1` slab out, `R2` slab in, `R3` ridge, `R4` channel, `R5` action button (slab that goes in
when selected), `R6` default action button (extra highlighted ring, e.g. "OK"), `R7` editable field well; optional
`,n` = Wimp colour used for the selected/highlight state, e.g. `R6,3`),
`S` sprite names `Sname,pressedname` (second shown when `selected`). Sprite names come from the Wimp pool
(`Wimp/Sprites22`) unless the app has its own.

## 3. Messages and help

`assets/messages/<Pool>.json` — flat `{token: value}` from MessageTrans files. `a/b:value` defines both a and b;
`#` comments dropped; parameters `%0`–`%3` left verbatim (substitute at runtime), `%%` = literal percent.
Wimp's own is `Wimp.json`; Filer menus `Filer.json` (`MT…` tokens), Task manager `Switcher.json`, etc.
File list in `index.json`. `assets/help/<App>.txt` — each app's `!Help` text (LF line endings, Latin-1 decoded).

## 4. Fonts (`assets/fonts/`)

* `system8x8.json` — `{chars: [256][8]}`; row 0 top, bit 7 = leftmost pixel; chars 0-31 empty. From the kernel's
  Latin-1 font (`Kernel/s/vdu/vdufontl1`). `system8x8.png` = 16×16 grid of 8×8 cells, white on transparent
  (tint via canvas compositing). The VDU/BASIC driver should use this.
* **Outline fonts converted to real OpenType CFF (`.otf`) from the original RISC OS outlines** — include
  `assets/fonts/fonts.css`, then use these families (weights 400/700, style normal/italic):

  | RISC OS | CSS family | files | fallback |
  |---|---|---|---|
  | Homerton.Medium/.Bold/(.Oblique) | `Homerton` | Homerton-{Medium,Bold}[Italic].otf | Helvetica, Arial, sans-serif |
  | Trinity.Medium/.Bold/(.Italic) | `Trinity` | Trinity-*.otf | "Times New Roman", Times, serif |
  | Corpus.Medium/.Bold/(.Oblique) | `Corpus` | Corpus-*.otf | "Courier New", Courier, monospace |
  | NewHall.Medium/.Bold/(.Italic) | `NewHall` | NewHall-*.otf | "Century Schoolbook", Georgia, serif |
  | Sassoon.Primary/(.Bold) | `Sassoon` | Sassoon-*.otf | "Comic Sans MS", sans-serif |
  | Selwyn (dingbats), Sidney (symbol) | `Selwyn`, `Sidney` | char code = glyph code (not Unicode!) | — |
  | System.Medium / System.Fixed | `RISCOS System`, `RISCOS System Fixed` | | monospace |

  **Desktop font: `12pt "Homerton", Helvetica, Arial, sans-serif`** (Homerton.Medium 12pt, as in 3.71). RISC OS has
  180 OS units per inch, so at the default 1 px = 2 OS units (90 px/inch) 12pt = 12/72×90 = **15 px**: use
  `font: 15px "Homerton", Helvetica, Arial, sans-serif` for pixel-faithful sizing (or 12pt × zoom × 90/96 in CSS pt).
  `fonts.json` maps each RISC OS font name → `{family, weight, style, file, fallback, ascender, descender}` and has
  `latin1ToUnicode` for RISC OS Latin-1 bytes 0x80-0x9F (e.g. 0x8C → U+2026 …, 0x90 → ‘, 0x97 → –). Obliques are
  generated from the transformed-font stubs (`\M` matrix). Even-odd fills were re-oriented for non-zero rendering.
  Skeleton "stroke" lines (tiny-size hints) are dropped. Verified: `tests/screens/assets-fonts.png`.

## 5. Seed disc (`assets/disc/`)

`assets/disc/HardDisc4/…` mirrors `vendor/ro371/Install/HardDisc4` (17 MB in 1716 files). **Name encoding**
(per path component): any char outside `[A-Za-z0-9_-]` → `=` + 2 lower-case hex digits: `!Boot` → `=21Boot`,
`Drum+Cym` → `Drum=2bCym`, `"!Warning "` → `=21Warning=20`. Filetype is not in the stored name; see manifest.
Host-export conventions decoded: `,xxx` suffix = filetype, `,load-exec`, no suffix = Text (fff), host `.` = RISC OS `/`.

`manifest.json`: `{disc:"HardDisc4", totalBytes, files, root:{name:"$", type:"dir", children:[…]}}`; each node
`{name, type, size?, path?, load?, exec?, children?}` where `type` is a 3-hex filetype, `"dir"`, `"app"` (dir named `!…`)
or `"untyped"` (with `load`/`exec` hex). `path` is relative to `assets/disc/`. Contents: `!Boot` (Choices, Resources:
!System, !Scrap, !Fonts (outlines), !Configure, Textures…), `Apps` (!SciCalc, !Maestro, !Squash, !CloseUp, !ARPlayer
resources + BASIC `!RunImage,ffb` where applicable), `Diversions` (!Patience, !Blocks, !Clock, !Flasher, !MemNow,
!MineHunt, !Meteors, !Puzzle, !Player, AudioDemos…), `Images` (JPEG ,c85 + !SlideShow), `Manuals` (HTML ,faf + GIFs, !Bookworm),
`Printing`, `Sound` (Maestro ,af1 tunes), `Tutorials` (DrawTutor Map/Sign ,aff, PaintTutor Flower ,ff9, WelcomeGde, StarComms),
`Utilities`, `Replay`, `Video` (ReadMe/!Warning only). `Examples` (BASIC Wimp bridge demos !Doodle / Spiral / ReadMe) is added afterwards by
`node tools/basicwimp-demo.mjs` from `src/core/basicwimp/demo/` (`tools/build.mjs` runs it after `disc.mjs`). Skipped (listed with reasons in `skipped.json`, 36.7 MB):
absolute ,ff8 / module ,ffa / utility ,ffc / ,fc3 / ,d94 binaries, ARMovie codec data, videos and files > 2 MB.

## 6. Palette and filetypes

* `assets/palette.json`: `wimp` [16 × {index, hex, rgb, name}] (the 3.71 desktop palette from `Wimp/s/!Palette`:
  0 #ffffff … 7 #000000 greys, 8 #004499 dark blue, 9 #eeee00 yellow, 10 #00cc00 green, 11 #dd0000 red, 12 #eeeebb cream,
  13 #558800 dark green, 14 #ffbb00 orange, 15 #00bbff light blue), `wimpHex`, `border`, `pointer` [3], `vidc256` [256 hex]
  (default 256-colour palette from `Kernel/s/vdu/vdupal20`).
* `assets/filetypes.json`: `{"fff":"Text","ffb":"BASIC","ff9":"Sprite","aff":"DrawFile",…}` — 155 types from
  `Sources/HdrSrc/Derived/FileTypes` (the names the Filer shows), plus a few common later ones (JPEG c85, GIF 695, PNG b60…).
  The Filer icon for type `xxx` is `Wimp/Sprites22` `file_xxx` / `small_xxx`, falling back to `file_xxx`/`small_xxx` (generic).

## Browser testing note

`npx -y playwright@1` pulls a Playwright needing a newer Chromium than is cached; **use `npx -y playwright@1.61`**
(matches cached chromium-1228), e.g.
`npx -y playwright@1.61 screenshot --full-page --wait-for-timeout=3000 "http://localhost:8371/assets/sprites/index.html?pool=Wimp&file=Sprites22" out.png`.

## Report / status

Done: all six deliverables. Verified by screenshots in `tests/screens/assets-*.png` (Wimp Tools/Tools3d furniture,
Sprites22 file icons, textures, Patience cards, MineHunt, font specimen incl. accented composites + system font).

Gaps / caveats:
* Sprite colours for palette-less 1/2bpp sprites follow Wimp translation (as the desktop shows them), not the kernel
  default; 8bpp sprites with 16-entry palettes use the VIDC1 fold. 16/32bpp handled; CMYK/24bpp (not in 3.71) aren't.
* Fonts cover the Latin-1 repertoire only (Base0 glyphs beyond Latin-1, e.g. Greek in Homerton, are not exported);
  no kerning table exported (IntMetrics kern pairs are ignored). Hinting/scaffold not converted.
* Disc has no extra (non-Acorn) samples: only 3 Drawfiles and ~40 BASIC files exist on the original HardDisc4.
  More Drawfiles exist in `Sources/Demos/Tutorials` (Butterfly, Plaque) if wanted.
* Messages pools include some internal-module files (e.g. `UK` = Territory UK); harmless.
