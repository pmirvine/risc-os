!Doodle - a small Wimp application written in BBC BASIC V
==========================================================

This is an example of an ordinary tokenised BASIC Wimp program (!RunImage).
It is run by the BASIC Wimp SWI bridge, like any other BASIC desktop
application (for example the original !SciCalc).

Click on the icon bar icon to open the window.
In the window:
  SELECT  drops a blob of the current colour where you click
  ADJUST  changes the colour
  MENU    Info / Clear / Quit (ADJUST keeps the menu open)
  C       clears the window

Load !RunImage into Edit (Shift double-click) to see how it works.
